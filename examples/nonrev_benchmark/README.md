# nonrev_benchmark — standalone

Benchmarks two non-reversible ISOKANN isotargets (**Schur-ISA**, **GPCCA**) against the
reversible baselines (ISA, GramSchmidt, SVD-Power) on three systems: the `triple_well`
(benchmark_v3), `adp_300k_0p1` (benchmark_v4, vacuum alanine dipeptide, 300 K, τ=0.1 ps),
and a new non-reversible `directed_ring` toy. Theory + proof in notebook §6.

## This directory is self-contained
Everything the notebook needs is bundled here, so the other benchmark directories
(`benchmark/`, `benchmark_v2/`, `benchmark_v3/`, `benchmark_v4/`, and `non_reversible/`)
**can be deleted.** The only external dependency is the installed `amore` package
(`AMORE/src/amore`: `isotarget`, `isokann`, `scrna.koopman`).

```
nonrev_benchmark.ipynb     the deliverable — loads cached runs, recomputes all tables/figures live
toy_systems.py             the 3 systems + bundled reference solutions
nonrev_targets.py          Schur-ISA / GPCCA wired to the AMORE isotarget pipeline
schur_isotargets.py        the two transforms (vendored; also in non_reversible/)
train_eval.py              training harness + scoring (Hungarian |r|, fate AUROC, SD/k_eff)
run_benchmark.py           batch driver -> runs/ cache
theory_demo.py             §6 demonstration (iterate precesses on the directed ring)
data/                      bundled reference data (TW committors, ADP 0.1ps, ring cache)
runs/                      cached training results (chi_best per variant/seed)
figures/                   theory_rotation.png
```

## Reproduce
```
conda run -p <amore-env> python run_benchmark.py     # (re)populate runs/  (~45 min CPU)
conda run -p <amore-env> jupyter nbconvert --to notebook --execute --inplace nonrev_benchmark.ipynb
```
Delete `runs/` to retrain from scratch; the notebook also retrains any missing run on demand.

## Bundled reference solutions (`data/`)
- `triple_well_koopman.npz` — TW anchors + Koopman bursts (was benchmark/data)
- `tw_committor.npz` — TW FEM committors p_A, p_B, p_C (was benchmark_v2/panel0)
- `vac_{X0,Xtau,phi0,psi0,phitau,psitau}_T300_0p1.npy` — ADP 0.1 ps coords + dihedrals;
  the φ/ψ reference operator (EV2, EV3) is rebuilt fresh from the transition pairs (was benchmark_v4/data)
- `ring_*.npz` — directed-ring cache (self-generated by `toy_systems.simulate_directed_ring`)
